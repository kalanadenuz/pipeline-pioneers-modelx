# Problem Formulation: Kelani River Downstream Floodplain
Low-lying agricultural communities face delayed flood waves...
## Geographic Focus
Kelani River Basin: 2,292 km² drainage basin in southwestern Sri Lanka.
## Target Towns
Hanwella, Biyagama, Kaduwela, Kolonnawa.
Agricultural loss: LKR 250k-600k per season.
## Prescriptive Action
Alert outputs: 'Dismantle water pumps and move tractors before 02:00 AM'.
